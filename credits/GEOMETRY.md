# Polygon buffers

Standalone bundle vendor/turf-buffer.mjs, @turf/buffer 7.2.0, bundled with esbuild 0.25.0. Package versions and original licensing declarations: geometry/dependencies.json; available package license files in geometry/. Turf MIT, d3 ISC, JSTS EDL-1.0 OR EPL-1.0 (EDL-1.0 distribution chosen).

Source: https://github.com/Turfjs/turf and https://github.com/bjornharrtell/jsts and https://github.com/Turfjs/turf-jsts.

Regenerate with npm install --prefix .cache/geometry --ignore-scripts @turf/buffer@7.2.0 esbuild@0.25.0, then esbuild bundle/format esm/platform browser/minify/legalComments inline. Geometry is approximate geodesic buffering, not a cadastral survey.
