# Pokyny projektu Vítr v krajině

Komunikuj česky. Projekt je samostatný a nesmí měnit stakory-kosmonosy ani původní izomapu. Čti README.md a docs/ISSUE-1.md. Zachovej zdroje, licence a oddělení simulation/existing/planned/approved. Neodvozuj konkrétní stavby ze zón a nevymýšlej rozměry. Výškopis bez ověřeného vertikálního data nesmí být označen jako geodeticky přesný. Před předáním npm test a npm run build. Aktualizuj docs/VALIDATION.md skutečnými výsledky, nikoli přáními. .cache a ZIP do Gitu nepatří.
